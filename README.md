2026年ジョイントコンサート用の交流促進マッチングサイトです。
app.jsで全体の変数設定、.htmlで各ページ情報を設定しています。

以下、引き継ぎ用（4年後の国内演旅マネの方へ）\\
こんにちは！2024年度演奏旅行マネージャーの吉浦拓海です。\\
企画、調整お疲れ様です！もしこのサイトを使いたいとのことでしたら、以下のように設定してください。\\
まず、サーバは無料版のFirebaseを使っています。自身のGoogleアカウントからFirebaseでプロジェクトを作成し、そこにサーバを置いてください。\\
サーバを置けたら、app.jsと各htmlファイルの最初にある部分を自分のプロジェクト名（作成時に途中でコピーできるものがはず）に置き換えてください。\\
それが終わったら、create.htmlの日時等々を変更してください。（デフォルトでは2026/1/1~2026/2/23とかになってるはずです）\\
ロゴの変更はevent.htmlから参照pngを差し替えればできるはずです。この画像データもgithub内に入れることを忘れないように！\\
後は基本的にそのまま運用可能なはずです。頑張って！\\

以下詳細設定\\
1日のログイン上限は60000回、書き込み上限は10000回です。\\
1人当たりのイベント作成可能回数は5回です。（app.jsやcreate.htmlから変更可）\\
1つのイベントに対して、参加は1端末につき1回までしかできません（なりすまし防止のため）\\
画像のアップロードは無料版Firebaseでは基本的にできません。フリー画像の置いてあるサイトからリンクを引っ張ってきてください。\\
もし、どうしてもgoogleフォームの様に画像をアップロードさせたい場合はFirebaseを有料版にアップグレードさせたうえで、僕に連絡するかchatgptに頼んでください。\\

他に何かあれば、歴代幹事会のLineグループから僕に直接連絡してください。
